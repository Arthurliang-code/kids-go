# 萌宝少儿围棋 (Kids Go Master)

专为少儿打造的趣味围棋启蒙与智能对弈 Web 应用。卡通高颜值设计，支持平板触控与电脑鼠标，零依赖离线开箱即用。

---

## 🌟 核心功能特色

### 1. 📖 围棋基础知识趣味闯关 (Knowledge Academy)
循序渐进的闯关教学题库，每关配有卡通导师讲解、互动操作、即时正向反馈：
- **第1关：数数单子的“气”**（认识十字交叉呼吸线）
- **第2关：角落和边缘的气**（理解角少边多腹地广）
- **第3关：嗷呜！“提子”大开吃**（堵满所有气吃掉对方）
- **第4关：发出警告！“打吃”！**（叫吃与威胁）
- **第5关：危险！快救救小黑棋**（逃子与长气自救）
- **第6关：小心陷阱！“禁着点”**（自杀禁入规则识别）
- **第7关：连环门！少儿技巧【门吃】**
- **第8关：温柔陷阱！少儿技巧【抱吃】**
- **第9关：做活大龙！【两只真眼】**（两眼活棋死活核心）
- **第10关：羊角冲锋！少儿技巧【扭羊头（征子）】**

### 2. 📢 专属高清晰度语音朗读（专为不识字幼童定制）
- **国标级极清播音原声**：默认采用国标级标准普通话播音（婷婷），无压缩无杂音，字正腔圆，咬字极为清脆清晰，吐字如大珠小珠落玉盘。
- **3 款高清晰名师音色自选**：
  - 🎙️ **国标播音 · 婷婷**（字正腔圆，咬字最清晰最标准，推荐首选）
  - 👩‍🏫 **温柔幼教 · 美佳**（清脆柔和幼师音）
  - 👨‍🏫 **沉稳名师 · 睿德**（厚重清晰的围棋大师男声）
- **无压缩无损音质**：采用 16-bit 22.05kHz 纯净 WAV 音频直出，彻底告别失真低清压缩。
- **听师傅读题**：每道题目配有专属亲切口语化解说，点击“听师傅读题”按钮随时重听。
- **自动语音播报**：切换关卡自动朗读题目要求与规则，不识字也能无障碍理解题意。
- **生动萌宠嘴部动效与答题语音反馈**：朗读时熊猫师傅头像活泼跳动与发光；答对获得表扬，按错给予温柔引导。
- **顶部快速开关**：家长可随时在顶部点击“🗣️”图标开启或关闭自动朗读。

### 3. ⚔️ 萌宠段位智能对战（自适应动态难度更新）
- **5大卡通对手与等级梯队**：
  - 🐰 **18K 萌新小兔**（吃子棋学徒，适合零基础幼童，经常可爱走神）
  - 🦊 **14K 机智小狐**（机灵探索者，懂护气与抓破绽）
  - 🦌 **10K 沉着小鹿**（森林围地家，金角银边稳扎稳打）
  - 🐘 **5K 威武大象**（破阵大将军，攻守兼备两眼做活）
  - 🐼 **1D 神算熊猫**（棋圣大宗师，高阶启发式棋局研判）
- **动态升降级机制**：
  - 连胜自动晋升段位，解锁新萌宠对手与更高难度。
  - 连败触发“温柔放水与鼓励机制”，保护孩子学习兴趣与信心。
- **儿童友好玩法与辅助器**：
  - **吃子棋模式**（先吃3子或5子即胜，正向反馈极强）与**正规围地数子模式**。
  - 棋盘规格自选：9路盘（快速局）、13路盘（中盘实战）、19路盘（标准大盘）。
  - 🟢 **实时气数透视**：棋子上实时标识剩余气数（1气高危红光报警、2气黄圈、3+气绿圈）。
  - 💡 **熊猫师傅支招**：遇困时一键获取推荐落子点。
  - 悔棋与重新开局功能。

### 4. 📱 专为平板与触控设计的交互 (Touch & iPad Optimized)
- **防手指遮挡放大准星 (Touch Loupe)**：在触控屏上滑动选点时，悬浮准星自动浮于手指上方并吸附最近交叉点，彻底解决小手点不准或手指挡住棋盘的痛点。
- **弹性卡通大按钮与护眼木纹**：暖色木质棋盘质感，逼真 3D 黑白棋子。
- **纯原生 Web Audio 合成音效**：清脆落子木声、提子泡泡欢呼声、打吃警报声、胜利号角，无需联网下载外部音频，无跨域限制。

### 5. 🏅 围棋小大师勋章馆
- 通关关卡与升级对弈均可点亮专属荣誉勋章，记录少儿每一步成长。

## 📱 iPad 独立全屏 App 运行方式（最推荐）

本项目已完整配置为 **Apple PWA 独立全屏桌面应用**（带 Service Worker 本地离线缓存，无边框、无 Safari 地址栏、断网依然秒开）：

### 操作步骤（仅需 10 秒）：
1. 在 Mac 终端运行投送脚本：
   ```bash
   cd "/Users/arthurliang/Documents/vibe coding/kids 围棋"
   ./start_ipad_server.py
   ```
2. 在 iPad 的 **Safari 浏览器** 中打开终端显示的局域网地址（如 `http://192.168.x.x:8088`）。
3. 点击 Safari 右上角 **【分享按钮（带向上箭头的方框）】**。
4. 下滑选择 **【添加到主屏幕】(Add to Home Screen)** ➔ 点击右上角【添加】。
5. **完成！** iPad 桌面上将生成原生的【萌宝围棋】卡通图标，点击即可像真实 App 一样全屏沉浸下棋，且后续无需网络即可离线秒开！
