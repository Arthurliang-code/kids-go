# 🐼 萌宝少儿围棋 (Kids Go Master)

专为少儿打造的趣味围棋启蒙与智能对弈 Web / iPad 应用。搭载 **Microsoft Edge Neural TTS（微软神经网络真人级少儿语音）**，支持平板触控防遮挡准星、40 关“先教学再练习”四大阶段进阶体系、5 级卡通段位对战，并提供 **在线即玩** 与 **iPad 纯本地离线独立包**。

- 🌐 **在线直接体验（支持微信 / iPad Safari 一键放到桌面）**：[https://arthurliang-code.github.io/kids-go/](https://arthurliang-code.github.io/kids-go/)

### 3. ⚔️ 双对战模式与地盘势力雷达
- **两大儿童友好对弈玩法**：
  - **⚔️ 吃子大战**：默认统一设定为**吃满 5 子获胜**，给予更充裕的中盘手筋与死活交锋空间。
  - **🏰 庄园争夺战**：支持 7 路与 9 路围地争夺，双方连续停一手（Double Pass）或达到步数上限自动清算地盘目数。
- **🌌 实时地盘势力雷达 (Territory & Influence Radar)**：
  - 基于 Conway 扩散场算法在棋盘动态渲染两军领地光晕（黑方青翠光晕、白方橙暖光晕），让抽象的“势力与空”对儿童肉眼可见。
- **5 大卡通对手自适应难度梯队**：
  - 🐰 **18K 萌新小兔** ➔ 🦊 **14K 机智小狐** ➔ 🦌 **10K 沉着小鹿** ➔ 🐘 **5K 威武大象** ➔ 🐼 **1D 神算熊猫**。
  - 搭载 12 项手筋模式识别器，实战中打出高阶手筋以静默胶囊呈现“🌟 学以致用”，支持点击跳转复习对应关卡。

## 🛠️ 本地运行与构建

1. **执行 AGENTS.md 规范全量自动化回归测试**：
   ```bash
   node -c js/go-engine.js && node -c js/puzzles.js && node -c js/ai.js && node -c js/voice.js && node -c js/app.js && node -c sw.js && node tests/browser_runtime.test.js && node tests/integrity.test.js
   ```
2. **启动局域网预览与实时 Edge-TTS 调试服务**：
   ```bash
   python3 start_ipad_server.py
   ```
3. **一键重新打包单文件离线 HTML 与 iPad 桌面离线描述文件**：
   ```bash
   python3 build_standalone.py
   ```
