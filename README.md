# 🐼 萌宝少儿围棋 (Kids Go Master)

专为少儿打造的趣味围棋启蒙与智能对弈 Web / iPad 应用。搭载 **Microsoft Edge Neural TTS（微软神经网络真人级少儿语音）**，支持平板触控防遮挡准星、10 关互动教学、5 级萌宠段位对战，并提供 **在线即玩** 与 **iPad 纯本地离线独立包**。

- 🌐 **在线直接体验（支持微信 / iPad Safari 一键放到桌面）**：[https://arthurliang-code.github.io/kids-go/](https://arthurliang-code.github.io/kids-go/)
- 📲 **iPad 纯离线桌面图标安装包**：[`KidsGo_iPad_Offline.mobileconfig`](./KidsGo_iPad_Offline.mobileconfig)
- 📦 **全内嵌单文件离线 HTML 版**：[`萌宝少儿围棋_iPad离线单文件版.html`](./萌宝少儿围棋_iPad离线单文件版.html)

## 🌟 核心功能特色

### 1. 📖 围棋基础知识趣味闯关 (Knowledge Academy)
循序渐进的闯关教学题库，每关配有卡通导师讲解、互动操作、即时正向反馈：
- **第1关：数数单子的“气”**（认识十字交叉呼吸线）
- **第2关：角落和边缘的气**（理解角少边多腹地广）
- **第3关：嗷呜！“提子”大开吃**（堵满所有气吃掉对方）
- **第4关：发出警告！“打吃”！**（叫吃与威胁）
- **第5关：危险！快救救小黑棋**（逃子与长气自救）
- **第6关：小心陷阱！“禁着点”**（自杀禁入规则识别）
- **第7关：连环门！少儿技巧【门吃】**
- **第8关：温柔陷阱！少儿技巧【抱吃】**
- **第9关：做活大龙！【两只真眼】**（两眼活棋死活核心）
- **第10关：羊角冲锋！少儿技巧【扭羊头（征子）】**

### 2. 📢 微软 Edge Neural 真人级少儿语音（专为不识字幼童定制）
- **4 款少儿专属 Neural 音色自由切换**（共预置 112 条高清神经网络语音片段，离线秒播）：
  - 🌟 **晓晓老师 (`zh-CN-XiaoxiaoNeural`)**：温暖少儿故事王牌女声（默认推荐）
  - 👧 **晓伊姐姐 (`zh-CN-XiaoyiNeural`)**：甜美动漫萌音，深受低龄儿童喜爱
  - 👦 **云夏弟弟 (`zh-CN-YunxiaNeural`)**：专为儿童动画与游戏打造的活泼正太童声
  - 🐼 **云希哥哥 (`zh-CN-YunxiNeural`)**：阳光温暖的熊猫师傅男声
- **听师傅读题 + 自动语音播报**：切换关卡自动朗读题目要求与规则，答对欢呼表扬、点错温柔引导，对弈提子/打吃/晋级均有专属语音互动。

### 3. ⚔️ 萌宠段位智能对战（自适应动态难度）
- **5 大卡通对手与等级梯队**：
  - 🐰 **18K 萌新小兔** ➔ 🦊 **14K 机智小狐** ➔ 🦌 **10K 沉着小鹿** ➔ 🐘 **5K 威武大象** ➔ 🐼 **1D 神算熊猫**
- **儿童友好玩法与辅助器**：
  - 支持 **吃子棋模式**（先吃 3 子或 5 子获胜）与 **标准围地数子模式**。
  - 支持 **9 路 / 13 路 / 19 路** 棋盘切换。
  - 🟢 **实时气数与打吃危险角标**、💡 **熊猫师傅支招**、↩️ **一键悔棋**。

### 4. 👵 专为异地长辈与儿童设计的 iPad 桌面安装体验
- 页面右上角内置 **「📲 放到桌面」** 绿色大按钮，自动识别 **微信内置浏览器** 或 **Safari**，弹出超大字体的 2 步傻瓜式图文引导。
- 内置 Service Worker (`sw.js`) 离线引擎，添加到 iPad 主屏幕后自动缓存全部代码与 4 套真人语音包，断网/飞行模式照常畅玩。

## 🛠️ 本地运行与重新打包

1. **启动局域网预览与实时 Edge-TTS 语音合成服务**：
   ```bash
   python3 start_ipad_server.py
   ```
2. **一键重新打包单文件离线 HTML 与 iPad 桌面离线安装包**：
   ```bash
   python3 build_standalone.py
   ```
